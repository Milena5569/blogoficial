# VivaTDAH Blog Hub

A high-performance mental health content platform focused on ADHD education.

This project evolves a traditional blog into a structured **Content + Growth Platform**.

---

## Stack

Payload CMS  
MongoDB  
Astro SSR  
React Islands  
Tailwind CSS  
TypeScript

---

## Key Goals

• high SEO performance  
• editorial trust signals  
• structured learning journeys  
• scalable architecture

---

## Architecture Principle

Payload CMS is the **single source of truth** for all editorial and community data.
